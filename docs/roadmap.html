Roadmap

From a verified foundation to a Blender-native runtime.

Each milestone ends with a runnable artifact and a measured result. The ordering is deliberate: correctness and observability first, content and scale later.

Principles

Standalone first

The runtime must run games without Blender installed. The bridge is an addon, never a runtime dependency.

Simulation ≠ rendering

Fixed-step gameplay, decoupled visual interpolation. Frame rate changes must not change behaviour.

Prove it on screen

Every rendering milestone is verified with a headless screenshot and a performance number, not just a successful compile.

Profile before optimizing

Built-in CPU/GPU timings and deterministic replay arrive before large-scale rendering work.

Blender is the editor

We will not rebuild Blender's editor. We will make the engine a first-class Blender target.

Clean-room forever

No copied BGE code, no accidental GPL contamination, documented third-party licenses.

Phases

M0 · DONE

Foundation

A buildable engine skeleton and a verified, good-looking demo.

  • Repository layout, design docs, zero-install Zig build (plus CMake)
  • Logging, math, ECS, job system, fixed timestep
  • Win32 window, OpenGL 4.6 context, input
  • HDR PBR renderer, directional shadows, instancing, post
  • Sandbox demo and headless screenshot
  • Unit tests (32 checks) and HTML documentation

Exit: python build.py run is stable, python build.py test passes, and the screenshot is reproducible. Met.

M1 · CURRENT

Playable runtime

  • Blender scene export/import (.bgescene) with all light types, world, camera and materials
  • Runtime scene serialization: the engine writes and reads the same format
  • Embedded CPython host with a bge module (bge.types, bge.objects, bge.app.handlers)
  • Built-in rigid body solver as a Jolt stand-in
  • Prefabs, a cooked pack and a scene switching API
  • Jolt physics, character controller, collision events
  • Gamepad input, audio (miniaudio), debug UI
  • glTF, PNG/DDS, hot reload, runtime profiler

Exit: a walkable level with physics, Python gameplay, audio, and a saved scene.

SCOPE

Not in scope

  • Freestyle line rendering
  • Grease Pencil
  • Movie clips and the sequencer
  • Multi-view (stereo) rendering
M2

Rendering and content pipeline

  • Cooked packs, dependency tracking, texture compression
  • Normal maps, decals, material variants
  • Cascaded shadows, clustered point/spot lights
  • SSAO, bloom, color grading, TAA/FXAA
  • Skeletal animation, blend trees, events
  • Particles and improved GPU instancing
M3 · PARTIAL

Blender live link

  • Blender add-on: export, play, stop and package from the 3D View sidebar
  • Live link: the engine reloads the scene in place when the scene file changes
  • Engine preview: the engine renders the scene and the frames are mirrored into Blender
  • Game template and packaging into a self contained game folder
  • Socket based push with incremental mesh, material and transform updates
  • Bidirectional selection and entity inspection
  • Bake lighting/occlusion back into engine data

Exit: the 2.49b workflow — edit in Blender, press Play, see the game — with no manual export step.

M4

Tooling and shipping

  • Standalone inspector, outliner, profiler timeline
  • One-click package/export (executable + pack)
  • Crash reporting and deterministic replay
  • Validation layers and automated performance tests
M5

Scale and platforms

  • Vulkan RHI, render graph, bindless resources
  • Linux target and Steam Deck verification
  • GPU-driven culling and streaming worlds
  • Networking with snapshot/rollback-friendly APIs
