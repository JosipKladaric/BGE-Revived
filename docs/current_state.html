Verified on this machine

OpenGL 4.6

Context creation, vendor and version query verified via WGL on Intel UHD Graphics.

Three build paths

build.py with Zig, CMake + Ninja, and a MinGW-w64 toolchain all compile the engine, sandbox and tests.

Blender round trip

Blender 4.4.3 exports a scene with sun, area, point and spot lights; the engine renders it headlessly and matches the Cycles reference.

Scripting

Embedded CPython 3.12 runs a script that animates the demo scene through the bge module.

Shared memory frames

The add-on reads preview frames from a named region instead of the socket: about 7 ms for a 1600x900 frame, and microseconds when the engine has nothing new.

Jolt physics

A Blender scene with a passive floor and three falling crates simulates in bge_game: the crates are airborne on the first frame and resting on the floor after 150 frames (build/physics_f1.png, build/physics_f150.png).

Out of scope

Freestyle line rendering, Grease Pencil, movie clips / sequencer and multi-view (stereo) rendering are deliberately not implemented.

Known gaps

  • Environment maps are sampled with a lat-long mapping whose vertical axis is offset from Blender's Generated coordinates.
  • Only the first sun light casts shadows; point, spot and area lights are unshadowed.
  • Area lights widen roughness instead of using a rectangular-light integral (LTC).
  • AgX / Filmic colour management is approximated with an ACES curve; Standard is exact.
  • No EXR environment support, no audio, networking or UI yet.
  • Jolt creates boxes and spheres only: capsule, convex hull and mesh collision shapes fall back to an enclosing box. Constraints, the character controller and ray casts are not exposed yet.
  • No CI; this machine currently has no Git installation.
